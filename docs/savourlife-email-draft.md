# Draft email to SavourLife (not sent)

**To:** adoptadog@savour-life.com.au
**Subject:** Rescue software integration - Cape Animal Protection Shelter (CAPS)

Hi SavourLife team,

I'm writing on behalf of Cape Animal Protection Shelter (CAPS) in Weipa, Queensland. We list our dogs on SavourLife Pet Adoptions and are very happy with it.

We've recently built our own shelter management system (replacing a set of spreadsheets), and we'd like it to send our dogs to SavourLife directly so staff only enter each dog once. We understand rescues using Animal Shelter Manager do this with an authentication token, and we'd like to do the same from our own system.

Could you please let us know:

1. Whether you're happy for us to connect our system to the same interface Animal Shelter Manager uses, and if so, the technical documentation for it (the web address, the format of the requests for adding or updating a dog, marking a dog adopted, and removing a dog).
2. The list of breeds and their numbers (the breed IDs) so we can match our breed names to yours.
3. Whether photos should be sent as web addresses or uploaded as files, and any limits on number, size or order (your manual says up to 10 photos with the first as the main square image).
4. Whether videos can be added this way or only through your Vimeo upload page.
5. How we should mark a dog as on hold, on trial, and adopted (with the enquiry number).

We'd generate our own token from our SavourLife account as in your manual (My Account, Generate Token) and keep it private. We're also happy to start with one dog as a test, or to be told it isn't something you support yet - in that case we'll keep entering dogs by hand.

Thank you for all the work you do for rescue groups.

Kind regards,
Paul Green
Cape Animal Protection Shelter (CAPS)
consult@capeanimalprotectionshelter.org.au
